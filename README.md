# nutrition_vs_obesity_trends
In this repo we've analysed the various factors that contribute to the health and nutrition of a person.

Used three datasets for analysis
1. 2025-food-environment-atlas-data.xlsx
2. ObesityDataSet_raw_and_data_sinthetic.csv
3. table-3-US-nutrient-intake-and-share-by-food-source.xlsx

Resources for this data:
1. https://www.ers.usda.gov/data-products/food-environment-atlas/data-access-and-documentation-downloads
2. https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition
3. https://www.ers.usda.gov/data-products/food-consumption-nutrient-intakes-and-diet-quality (Table 3)
